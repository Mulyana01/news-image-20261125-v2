# The World in One Day — Wednesday, 25 November 2026

One image, one day: 32 dated stories from Wednesday, 25 November 2026, clipped from the wires and pasted up as a newspaper-collage broadsheet. A Hormuz mine crisis leads the page, over a UTC timeline of the day, a dot map of where it all happened, and eight regional clippings spanning 13 fields — war, markets, tech, space, health, climate, courts, disasters and sport. Every story is dated Wednesday 25 November 2026 and was checked against wire timestamps before printing (see the DATE CHECK box on the page).

## How it was made

The broadsheet was composed as a single HTML page (`index.html`) — masthead, UTC timeline, dot-matrix world map and 13 pictured stories drawn as inline SVG — styled as a paper-cut clipping collage on a kraft board, then rendered to PNG with headless Chromium at 2048×2048 and downscaled to exactly 1024×1024 (Lanczos, palette-quantized) as `entry.png`. Every word is set in type, so nothing is misspelled by an image model.

Run:

```
node main.ts
```

`main.ts` copies the sibling `entry.png` into `$MAKEFUN_OUTPUT_DIR` (falling back to `/output`).
